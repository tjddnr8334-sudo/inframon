# ⑥ 광역 모니터링 — 지자체 전체 교량 InSAR 감시

단일 교량을 골라 해석하던 흐름(⓪~④)에 더해, **시·군 하나(또는 도 전체)의 모든 교량**을 Sentinel-1 새 영상이 나올 때마다
자동으로 판정하고, 문제가 생긴 교량만 알람으로 올린다. 알람이 난 교량은 버튼 하나로 `project.h5` 로 내보내 ②PINN·③FRAM·④잔존수명으로 이어서 본다.

## 구성
| 부분 | 위치 | 역할 |
|---|---|---|
| 엔진 | [bridge-insar-monitor](https://github.com/tjddnr8334-sudo/bridge-insar-monitor) (CLI) | 교량대장 → 궤도 탐색 → 버스트 증분 다운로드 → 기준 격자 정합(보간) → StaMPS PS(산악지 적응형) → 품질필터(기선 200 m, 기준점 결맞음 0.95→0.80 단계) → 열 신축 보정 → 허용변위 판정 → Capon·APES·DS 보강 → 교대부 대체 → 알람·처리오류·이력 |
| 판독 | `inframon.region` | 엔진 산출물(state·alerts·health·history) 판독, 시군구 교량 목록, life.limits 기준 비율 확인, 교량 → project.h5 내보내기 |
| 화면 | 대시보드 ⑥ 탭 (`dashboard/region_tab.py`) | 교량 알람·처리 오류 알람, 지도·필터 목록, 교량별 LOS/수직/열보정 시계열, 판정 이력, 내보내기 |
| CLI | `--region` `--region-update` `--region-report` `--region-export` | 주기 실행·요약·내보내기 |

GPL 도구(ISCE2·StaMPS)는 엔진에서 CLI 로만 실행한다(CONTRIBUTING).

## 실행
```bash
python -m inframon --region configs/gangneung_region/region.json                 # 현황 요약
python -m inframon --region configs/gangneung_region/region.json --region-update # 한 주기(새 영상 없으면 즉시 종료)
python -m inframon --region configs/gangneung_region/region.json --region-export b1a2b3c4d5 --out data/region/x
```
주기 실행은 엔진의 `deploy/bim-update.timer`(매일 03:00, 새 영상 없으면 즉시 종료)로 걸어 둔다. Sentinel-1 재방문은 12일(2025년부터 1A·1C)이다.

## 판정과 한계값
- 측정량: 첫 촬영일 이후 **주변 지반(30–300 m) 대비** 누적 수직변위(LOS ÷ cos 입사각, 열 신축 보정)와 인접 지점 부등변위.
- 허용값은 inframon `life.limits.DEFAULTS` 로 통일: 침하 25 mm, 각변위 1/500(모든 형식). 엔진 criteria.yaml 도 같은 값을 쓴다.
- 비율 = 측정 / 허용. 종별(1·2·3종·기타) 비율 기준과 10년 예측(등급은 한 단계까지만 올림).
- 교량 위 PS 가 부족하거나 교대부 대체 판정이면 주의 이상이라도 "확인 필요"로 분리한다.

## 불확실성 (온도·자료 공백)
판정 등급은 중앙값으로 정하되, 교량마다 오차 범위를 함께 낸다.
- 측정 오차: 지점부 변위속도 추세의 표준오차 + 주변 지반 기준의 불확실성(지반 PS 산포 / √n), 2σ
- 온도: 열 신축 보정 전후 누적변위 차이(ERA5 0.25° 기온을 쓰므로 상판 실제 온도와 다를 수 있다)
- 자료 공백: 사용 영상 / 예상 영상(12일 주기)으로 오차를 키우고, 커버율 60 % 미만·최장 공백 365일 초과·마지막 영상 60일 경과면 '자료 공백' 표시
- 범위(하한~상한)가 등급 경계를 넘거나 자료 공백이면 주의 이상이라도 **확인 필요**로 분리한다. 알람·대시보드·IFC 에 범위와 사유가 같이 나간다.

## 교량별 IFC
`--region-ifc DIR` 또는 ⑥ 탭의 "🏗️ 이 교량 IFC 만들기" — 전국교량표준데이터 제원(연장·폭·높이, 경간 = 형식별 대표값)으로 세운 프록시 부재
(상판 S1·교각 P#·코핑·교대 A1/A2, `bim.proxy_model`)에 속성을 붙인다: `Pset_BridgeRegistry`(대장), `Pset_InSAR_Monitoring`(판정·비율 범위·누적변위·한계값·불확실성·궤도),
`Pset_InSAR_Support`(교각·교대별 지점부 변위). 대장 시점·종점으로 EPSG:5179 `IfcMapConversion` 을 기록한다(pyproj 필요). 실도면 BIM 이 아니라 위치·형식·결과를 묶는 대체물이다.

## 변위 5단계 등급 (우수 · 양호 · 정상 · 주의 · 위험)
`--region-grade5` — 판정된 교량마다 **형식(연속/단순) · 경간 · 종별**에 따라 다른 허용값으로 5단계 등급을 낸다. 분포를 출력하고 `data/region/<이름>/grade5.csv` 에 교량별 등급·허용값·비율을 쓴다.
```bash
python -m inframon --region configs/gangwon_region/region.json --region-grade5
```
**법이 주는 것과 주지 않는 것**
| | 내용 | 출처 |
|---|---|---|
| 등급의 단계 | A 우수 · B 양호 · C 보통 · D 미흡 · E 불량 (여기서는 C·D·E 를 정상·주의·위험으로 부른다) | 시설물안전법 시행령 별표 8 |
| 어떤 변위가 d·e 인가(정성) | "기초의 부등침하로 교대/교각이 기울음" = d · "…상부구조의 단차 및 파손 발생" = e. 교각 부등침하는 중대한 결함 | 세부지침(안전점검·진단 편, 2021.12) 교량 [표 1.20]·[표 1.21] |
| 종별 | 1종 · 2종 · 3종 | 시설물안전법 |
| **몇 mm·몇 rad 인가** | **지침의 표에 수치가 없다** — 아래 설계기준·가정에서 가져온다 | — |
| 구조 한계 각변위 | 단순교 0.008 · 연속교 0.004 rad | AASHTO LRFD C10.5.2.2 (Moulton et al. 1985) |
| 관리 기준 | 각변위 1/500 · 침하 25 mm | inframon 기본 가정(보수적 조기 기준, 법정 수치 아님) |

**판정** — 관리 비율 `r_m = max(침하/25 mm, 각변위/(1/500))`, 구조 비율 `r_s = 각변위/구조 한계(형식별)`.
| 등급 | 조건 | 1종 | 2종 | 3종·기타 |
|---|---|---|---|---|
| 위험 (E) | `r_s ≥ 1` — 형식별 구조 한계 초과 | 단순 0.008 · 연속 0.004 | 같음 | 같음 |
| 주의 (D) | `r_m ≥` | 70 % | 80 % | 90 % |
| 정상 (C) | `r_m ≥` | 50 % | 60 % | 70 % |
| 양호 (B) | `r_m ≥` | 30 % | 40 % | 50 % |
| 우수 (A) | 그 밖 | | | |

- 크기(경간)는 허용 부등침하량에 들어간다: `허용 부등침하 = 각변위 한계 × 경간` (예: 단순교 경간 30 m → 구조 한계 240 mm, 관리 기준 60 mm). 경간을 모르면 형식별 대표 경간(연장 이하).
- 10년 예측이 더 나쁘면 한 단계만 올린다. **예측만으로 '위험'을 만들지는 않는다.**
- 종별 경계는 엔진의 관심·주의·경고 경계와 같은 값이라 기존 4단계와 어긋나지 않는다: 정상→우수 · 관심→양호 · 주의→정상 · 경고→주의, 구조 한계 초과만 새로 '위험'.
- 값을 바꾸려면 region.json 에 `"grade5": {"struct_beta": {"simple": 0.008, "continuous": 0.004}, "mgmt_beta": 0.002, "mgmt_settlement_mm": 25, "class_cuts": {"1종": [0.3, 0.5, 0.7]}}` — 바꾼 값은 출처가 '사용자 지정'으로 나온다.
- **이 등급은 위성 변위만으로 본 등급이다.** 법정 안전등급(A~E)은 균열·부식·내하력을 포함한 점검·진단으로 정한다. 이름만 맞춘 것이고 대신하지 않는다.
- `--region-push` 는 이 등급과 판정 과정·출처를 `summary_json.grade5` 로 함께 보낸다.

## Pontifex 로 보내기
`--region-push` — 판정을 Pontifex(교량 모니터링 플랫폼)의 **기존 교량**에 붙인다. `--pontifex-dry-run` 을 붙이면 무엇을 올릴지만 본다.
```bash
python -m inframon --region configs/gangwon_region/region.json --region-push --pontifex-dry-run
python -m inframon --region configs/gangwon_region/region.json --region-push            # 결과: data/region/<이름>/pontifex_push.json
```
- 교량 맞추기: 플랫폼의 같은 시·군 교량 중 **이름이 같고 300 m 이내**인 것. 못 찾거나 같은 이름이 겹치면(상·하행) 올리지 않고 목록으로 낸다 — 새로 등록하지 않는다.
- 올리지 않는 것: 미처리 · 판정 불가 · **확인 필요**(`--region-push-review` 로 포함, 레코드에 `review` 표기).
- 소스는 `inframon_region`, CRI 칸은 비운다(허용변위 비율은 CRI 가 아니다 — 비율·누적변위·한계값은 `summary_json`).
- 등급은 말이 같은 것끼리: 정상→정상(0) · 관심→주의(1) · 주의→주의(1) · 경고→경고(2). 순서대로 주려면 region.json 에 `"pontifex_levels": [0, 1, 2, 3]`.
- **결론과 근거를 같이 보낸다**: `summary_json` 에 `headline`(판정 이유 한 문장) · `action`(할 일 한 줄) · `series`(변위 시계열 — 열 신축 보정 수직 > 수직 > LOS 중 하나, 주변 지반 대비 mm). 플랫폼 교량 화면이 결론을 먼저 보이고 '근거 보기'로 수치·시계열을 펼치는 데 쓴다(관리자는 결론, 점검 용역사는 근거). 문장은 엔진 값만 옮긴다 — 정상이면 '조치 없음', 측정점이 적으면 그 사실을 문장에 넣는다.
- 관측일은 판정에 쓴 마지막 영상일. 같은 날짜를 다시 올리면 덮어쓴다. 되돌리기: `curl -X DELETE "<base>/api/ingest/sensing/?source=inframon_region"`.

2026-10-07 강원 전체: 판정 2,043개 중 확정(확인 필요 아님) 580개 → 플랫폼 교량과 일치 506개 전송(정상 493 · 주의 13), 74개는 이름 불일치·중복으로 제외.
