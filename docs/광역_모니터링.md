# ⑥ 광역 모니터링 — 지자체 전체 교량 InSAR 감시

단일 교량을 골라 해석하던 흐름(⓪~④)에 더해, **시·군 하나(또는 도 전체)의 모든 교량**을 Sentinel-1 새 영상이 나올 때마다
자동으로 판정하고, 문제가 생긴 교량만 알람으로 올린다. 알람이 난 교량은 버튼 하나로 `project.h5` 로 내보내 ②PINN·③FRAM·④잔존수명으로 이어서 본다.

## 구성
| 부분 | 위치 | 역할 |
|---|---|---|
| 엔진 | [bridge-insar-monitor](https://github.com/tjddnr8334-sudo/bridge-insar-monitor) (CLI) | 교량대장 → 궤도 탐색 → 버스트 증분 다운로드 → 기준 격자 정합(보간) → StaMPS PS(산악지 적응형) → 품질필터(기선 200 m, 기준점 결맞음 0.95→0.80 단계) → 열 신축 보정 → 허용변위 판정 → Capon·APES·DS 보강 → 교대부 대체 → 알람·처리오류·이력 |
| 판독 | `inframon.region` | 엔진 산출물(state·alerts·health·history) 판독, 시군구 교량 목록, life.limits 기준 비율 확인, 교량 → project.h5 내보내기 |
| 화면 | 대시보드 ⑥ 탭 (`dashboard/region_tab.py`) | 교량 알람·처리 오류 알람, 지도·필터 목록, 교량별 LOS/수직/열보정 시계열, 판정 이력, 내보내기 |
| CLI | `--region` `--region-update` `--region-report` `--region-export` | 주기 실행·요약·내보내기 |

GPL 도구(ISCE2·StaMPS)는 엔진에서 CLI 로만 실행한다(CONTRIBUTING).

## 실행
```bash
python -m inframon --region configs/gangneung_region/region.json                 # 현황 요약
python -m inframon --region configs/gangneung_region/region.json --region-update # 한 주기(새 영상 없으면 즉시 종료)
python -m inframon --region configs/gangneung_region/region.json --region-export b1a2b3c4d5 --out data/region/x
```
주기 실행은 엔진의 `deploy/bim-update.timer`(매일 03:00, 새 영상 없으면 즉시 종료)로 걸어 둔다. Sentinel-1 재방문은 12일(2025년부터 1A·1C)이다.

## 판정과 한계값
- 측정량: 첫 촬영일 이후 **주변 지반(30–300 m) 대비** 누적 수직변위(LOS ÷ cos 입사각, 열 신축 보정)와 인접 지점 부등변위.
- 허용값은 inframon `life.limits.DEFAULTS` 로 통일: 침하 25 mm, 각변위 1/500(모든 형식). 엔진 criteria.yaml 도 같은 값을 쓴다.
- 비율 = 측정 / 허용. 종별(1·2·3종·기타) 비율 기준과 10년 예측(등급은 한 단계까지만 올림).
- 교량 위 PS 가 부족하거나 교대부 대체 판정이면 주의 이상이라도 "확인 필요"로 분리한다.

## 불확실성 (온도·자료 공백)
판정 등급은 중앙값으로 정하되, 교량마다 오차 범위를 함께 낸다.
- 측정 오차: 지점부 변위속도 추세의 표준오차 + 주변 지반 기준의 불확실성(지반 PS 산포 / √n), 2σ
- 온도: 열 신축 보정 전후 누적변위 차이(ERA5 0.25° 기온을 쓰므로 상판 실제 온도와 다를 수 있다)
- 자료 공백: 사용 영상 / 예상 영상(12일 주기)으로 오차를 키우고, 커버율 60 % 미만·최장 공백 365일 초과·마지막 영상 60일 경과면 '자료 공백' 표시
- 범위(하한~상한)가 등급 경계를 넘거나 자료 공백이면 주의 이상이라도 **확인 필요**로 분리한다. 알람·대시보드·IFC 에 범위와 사유가 같이 나간다.

## 교량별 IFC
`--region-ifc DIR` 또는 ⑥ 탭의 "🏗️ 이 교량 IFC 만들기" — 전국교량표준데이터 제원(연장·폭·높이, 경간 = 형식별 대표값)으로 세운 프록시 부재
(상판 S1·교각 P#·코핑·교대 A1/A2, `bim.proxy_model`)에 속성을 붙인다: `Pset_BridgeRegistry`(대장), `Pset_InSAR_Monitoring`(판정·비율 범위·누적변위·한계값·불확실성·궤도),
`Pset_InSAR_Support`(교각·교대별 지점부 변위). 대장 시점·종점으로 EPSG:5179 `IfcMapConversion` 을 기록한다(pyproj 필요). 실도면 BIM 이 아니라 위치·형식·결과를 묶는 대체물이다.

## 한계
