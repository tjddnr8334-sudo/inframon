# 포터블 배포 — 타 컴퓨터에서 "압축 풀고 더블클릭"

> PyInstaller exe(`inframon.spec` + `packaging/install.ps1`)와 별개의 배포 레인.
> exe 는 빌드 시점 의존성이 고정되는 대신 Python 이 필요 없고, **포터블 zip 은 작고
> (소스만) 첫 실행에 모든 의존성을 스스로 설치**한다 — 연구실 다른 PC 에 옮겨 다니며
> 쓰는 용도라면 이쪽이 맞다.

## 만들기 (배포하는 쪽, 1 명령)

```powershell
powershell -ExecutionPolicy Bypass -File packaging\make_portable.ps1
# → dist\inframon_portable.zip
```

- `git archive`(추적 파일만)라 데이터·.venv·산출물은 안 들어간다 — zip 은 수 MB.
- 압축은 Windows 내장 bsdtar 로 — `Compress-Archive` 는 한글 파일명을 깨뜨려 쓰지 않는다.

## 쓰기 (받는 쪽 — 타 컴퓨터)

1. zip 을 원하는 폴더에 **폴더째** 압축 해제
2. **`INFRAMON_시작.bat` 더블클릭** — 끝.

첫 실행이 알아서 하는 일(`bootstrap.ps1`, 멱등):

| 단계 | 내용 | 없을 때 |
|---|---|---|
| Python 3.10+ 탐지 | `py -3.12/-3.11/-3.10` → `python` | **자동 설치**: winget → python.org 인스톨러(사용자 영역, 관리자 불필요) |
| 가상환경 | `%LOCALAPPDATA%\inframon\venv-<경로해시>` 생성 — 패키지 폴더가 깊어도 Windows MAX_PATH(260자)에 안 걸림(torch 내부 경로가 깊음). 시스템 파이썬 오염 없음 | — |
| 의존성 | `pip install -e .[dev,dashboard,search,hyp3,report,bim,pinn]` + pywebview | 수분~수십분, 수 GB — **pyproject 해시 마커**로 두 번째 실행부턴 건너뜀 |
| 구동 | `python -m inframon --app` (전용 창) | 실패 시 브라우저 대시보드(streamlit) 폴백 |

## 옵션 (환경변수 — bat 실행 전 `set` 또는 시스템 설정)

| 변수 | 효과 |
|---|---|
| `INFRAMON_FULL=1` | cv extra(transformers·대형)까지 설치 |
| `INFRAMON_EXTRAS=a,b,c` | 설치 extras 묶음 직접 지정 |
| `INFRAMON_NO_RUN=1` | 설치만 하고 실행 생략(프로비저닝 검증용) |

## 범위 밖 (의도적)

- **WSL/ISCE2(SARvey 레인)** — 시스템 기능 설치(관리자·재부팅)라 자동화하지 않는다.
  대시보드가 뜬 뒤 필요할 때: `python -m inframon --insar-tools` → `--insar-tools-install`.
  WSL 없이도 SNAP(`--snap-auto`)·HyP3(`--hyp3-insar`) 레인은 그대로 동작한다.
- **`insar` extra(gdal/mintpy)** — Windows pip 으로 설치가 깨지기 쉬워 기본 묶음에서 제외
  (conda 권장, `configs/README.md`). hyp3/gltf 에 필요한 rasterio 는 기본 묶음에 포함된다.
