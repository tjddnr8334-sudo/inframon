## 적어 둘 것

- CRI 등급은 **잠정** — 관측조건이 기준치 학습 조건과 다르다(노이즈 14.4mm vs 기준 10.0mm(1.4배) · 관측기간 2748d vs 기준 552d). 등급을 구조 상태로 읽으면 안 된다
- CSV 에 폭 없음 → OSM 보도 간격으로
- OSM 어느 way 도 연장 1160 m 와 안 맞음 (토막난 way) → 표준데이터 시점–종점 선분 사용
- OSM 보도 간격 8.4 m 는 등록 교량폭 35 m 와 크게 달라 쓰지 않았다(그 교량 보도가 아닐 수 있다)
- ⚠ '교면 위' 점이 지면보다 유의하게 **낮다**(z<−2) — 교면 산란체가 아닐 수 있다(제방·교대 주변 지면). 평면 선택을 다시 볼 것
- 형식별 상부구조: 트러스교 — 상현재 2련(데크 위 12 m) · 수직재 78본

## 이 파이프라인이 원리상 못 하는 것 (모든 교량 공통)

- **EI(강성) 관측 식별** — InSAR 는 상대 변위라 자중 처짐을 못 본다. EI·f₁ 은 설계 제원 기반이다(감사 ⓘ).
- **데크 위 PS 밀도** — Sentinel-1 화소 ~11 m. 프로그램으로 늘릴 수 없다. 고해상도 SAR·코너리플렉터가 답이다.
- **쉬프트 방향(각도)** — 궤도 heading 이 정한다. 크기 δh 만 잔차고도로 관측값이 된다.
- **쉬프트의 세 층** — A 기하(δh/tanθ, 보정) · B 처리 오프셋(지면 점 vs OSM 도로선으로 추정, 유의하면 제거) · C 산란체 위치(보도·난간 — 쉬프트가 아님). B 는 OSM 기준 상대값이라 3~5 m 아래는 못 본다.
- **시점 수** — 속도 95 % CI 는 시점 수와 기간이 정한다(101시점). 브리프 기준(≥100장)에 못 미치면 판정을 보류한다.

## 교면 전용 재선별

기존 선별은 교량 중심선 **±30 m** 였다 — 교량 폭보다 넓어 강변 지반이 섞였다.

## 기선망과 시간결맞음

점마다 `los = c + v·t + K·Δh (+ α·ΔT)` 를 같이 푼다. K 는 수직기선이 정하므로
**기선이 얼마나 벌어져 있는지가 잔차고도를 가를 수 있는지를 정한다.** γ 는 그 모형이
그 점을 얼마나 설명하는지이고, 값보다 **어디 있는 점이 살아남았는지**가 중요하다.

| 항목 | 값 |
|---|---|
| 처리 사슬 | SNAP |
| 시점 · 마스터 | 101시점 · 20220330 |
| 수직기선 B⊥ | -240.2 ~ +218.6 m (폭 459 m · σ 77.3 m) |
| 시간기선 | 2748 일 |
| 기선망 | 쌍 1125개 · 차수 최소 8 · 평균 22.3 · **연결됨** (문턱 B⊥ ≤ 150 m · Bt ≤ 400 일) |
| 높이 모호성 | B⊥=100 m 에서 164 m |
| **γ 중앙값** | **0.253** (문턱 0.35 → 204/536점 통과 (38 %)) |
| γ 통과 점이 어디 있나 | 교량 위(0~10 m) 3/26점 · 먼 맨땅(100~200 m) 81점 |
| 잔차고도 σΔh | 8.4 m — 형하고(8~25 m)보다 작다: 높이로 가려낼 여지가 있다 |
| APS 제거량 | RMS 2.76 mm · 잔차 16.3 → 11.2 mm |
