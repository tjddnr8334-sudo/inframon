# 4시 시연 — "좌표 하나로 끝까지"

## 준비 (발표 전 1분)

    python -m inframon --doctor          # SNAP·snaphu·Earthdata 유무 확인 — 화면에 보여줄 것
    python scripts/demo_4pm.py --open-only   # 결과 창이 열리는지 미리 확인

## 시연 (5분)

    python scripts/demo_4pm.py           # 정자교 · 44초 · 끝나면 결과 창 4개가 차례로 뜬다

터미널에 ①~⑩ 단계가 찍히는 동안 말할 것:

| 단계 | 화면 | 한 마디 |
|---|---|---|
| ① 제원 | `파트너 실측 CSV '정자교' (8 m)` | 좌표 하나로 CSV·OSM 에서 제원을 찾는다 |
| ④ 점 선택 | `처리 오프셋 ≈ 0 → … 산란체 위치` | 쉬프트를 세 층으로 가른다 — 남측 치우침은 보도 산란체 |
| ⑤ 잔차고도 | (결과.md) `+5.2 ± 1.2 m (z=4.31)` | 점이 **지면이 아니라 교면 위**임을 고도로 증명 |
| ⑥ IFC 트윈 | 3D 창 | IFC4 부재 A1·P1~P4·S1 위에 점 12개, 클릭하면 GlobalId |
| ⑦ CRI | `CRI 0.546 · 정상` | 같은 점으로 PINN 가상센싱 → 위험도 |
| ⑨ 감사 | `조건부` | 파일이 스스로 판정 — 어느 교량을 쓸지는 유저가 |

## 예상 질문

- **"쉬프트는?"** → 결과.md 하단. A(기하) 보정 · B(처리) 지면 점으로 ≈0 확인 · C(산란체) 남음.
- **"EI 는 관측인가?"** → 아니다, 원리상 불가. ⓘ 표기. InSAR 가 주는 것은 변위 속도·이상·위험도.
- **"다른 교량도 되나?"** → `docs/bridges/` 6개 전부 관통. `--batch`. 트랙 없으면 SLC 부터.
- **"SLC 는?"** → `--earthdata-save <토큰>` 한 번, 이후 자동. SNAP·snaphu 는 `--doctor` 가 안내.
- **"BMAP 전송은?"** → `--pontifex-mock` 으로 HTTP 왕복 확인(청양교 25+1건). 실 화면은 파트너.
