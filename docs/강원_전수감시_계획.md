# 강원 전수 감시 계획 — 교량 중심에서 버스트 중심으로

작성 2026-09-26. 근거 데이터는 `python scripts/region_inventory.py --sido 강원 --out data/gangwon` 으로 재생성된다
(`data/` 는 git 에 안 들어가므로 수치를 여기에 옮겨 적는다).

## 1. 바뀐 목표

1. **InSAR 정확도·신뢰도 상향이 1순위.** 교량 위 PS 점을 등간격에 가깝게 뽑는다.
   방법 4가지: SR-PSI(Capon/APES 재포커싱, 직접 구현) · DS 통합(MiaplPy, 이미 사용) ·
   APS 제거 후 재선별(StaMPS `weed_standard_dev`·`density_rand` 완화) · 상승+하강 궤도 결합.
2. 그래도 비는 구간은 PINN 가상센싱으로 채운다. 관측값과 보간값은 출처를 구분해 저장한다.
3. 이상 구간에 위험도를 산출한다.
4. **서비스 형태**: 사람이 UI 를 열어 보는 것이 아니라, Sentinel-1 을 우리가 보유하고 지자체별
   교량을 12일 주기로 자동 점검한다. 문제 교량만 알림 → 유지관리·현장 방문. 그 외 데이터는 보관.

첫 대상 지역은 **강원특별자치도 전체**, 파일럿은 **강릉시**.

## 3. 구조 전환: 왜 버스트 중심인가

지금 파이프라인(`pipeline_bridge.py`, `scripts/bridge_run.py`)은 교량 하나에 AOI 하나를 잡고 SLC 검색·다운로드·
정합을 교량마다 반복한다. 강원 4,255 개에 이 방식은 안 된다. 같은 버스트를 수백 번 받고 수백 번 정합하게 된다.

바꾸는 것:

1. **스택의 단위 = 버스트.** `data/gangwon/bursts.csv` 의 한 행이 스택 하나. ISCE topsStack 은 원래 버스트 단위로
   정합하므로 스택 코드는 그대로 쓰고, AOI 대신 버스트 ID 로 입력 범위를 정한다.
2. **교량은 스택의 소비자.** 정합·PS/DS 추출은 버스트 전체(또는 교량 주변 마스크 합집합)에서 한 번 하고,
   `bridges.csv` 의 asc_bursts/desc_bursts 로 교량별 점을 잘라 낸다. 교량 데크 마스크는 기존 OSM 축선 코드를 쓴다.
3. **12일 증분.** 새 날짜가 오면 버스트 스택에 SLC 한 장을 붙이고(기준 영상 고정) 그 버스트의 교량만 갱신한다.
   `schedule.py` 의 `monitor_cycle` 은 트랙 H5 하나를 받는 구조라 버스트→교량 팬아웃이 앞에 붙어야 한다.
4. **알림.** 현재 알림 채널이 없다(`schedule.py` 는 등급 상승만 표시). 위험도 등급이 오른 교량만 보내는
   출구(메일·웹훅)를 만든다. 지자체 단위 목록은 `bridges.csv` 의 시군구명·관리기관명으로 나눈다.

## 4. 단계

### M0 — 강릉 파일럿 (버스트 6개)

1. 상승 3 버스트 × 2025-01 이후 40 날짜, 하강 3 버스트 × 2025 이후 22/16 날짜 다운로드 (ASF 버스트 제품, 약 25 GB).
2. ISCE topsStack → MiaplPy 로 버스트별 PS+DS. 기준선: 내곡교 기존 결과(PS 25 · DS 184) 와 같은 방법으로 먼저 재현.
3. PS 밀도 4 방법을 **비용 낮은 순**으로 붙이고 매 단계 내곡교·강릉 ≥100 m 교량 159 개에서 점 수·데크 100 m 격자 채움률을 잰다.
   - ① APS 제거 후 재선별 (파라미터 완화, 반나절)
   - ② 상승+하강 결합 (하강 스택 완성되면 바로)
   - ③ DS 통합 임계 조정
   - ④ SR-PSI 구현 (Capon/APES, 코드 없음 — 가장 큼, 마지막)
4. 빈 격자는 PINN 보간, 보간 여부 열을 붙여 저장.
5. 산출: 강릉 ≥100 m 교량 159 개 각각 "실측 점 수 / 보간 격자 수 / 위험도" 표.

### M1 — 강원 전체 (버스트 42개)

M0 에서 확정한 파라미터로 42 버스트를 돌린다. 연장 < 100 m 교량 2,968 개는 같은 스택에서 나오는 점이 있으면 받고,
없으면 "관측 불가(연장 부족)" 로 기록한다. 억지로 보간하지 않는다.

### M2 — 12일 주기 운영

새 취득 감지 → 증분 정합 → 교량 갱신 → 위험도 재산출 → 등급 상승 교량만 알림. 지자체(시군구)별 목록으로 발송.

## 5. 원리상 안 되는 것 (미리 적어 둔다)

- **연장 50 m 미만 교량(강원 51%)**: Sentinel-1 지상 해상도 약 5 × 20 m 라 데크에 화소가 몇 개 안 된다.
  PS 가 안 잡히면 없다고 적는다. SR-PSI 로도 근본 해결은 안 된다.
- **하강 2022–2024 공백**: 그 기간의 연직 분리는 불가능하다. 상승 단일 궤도 LOS 만 있다.
- **PINN 보간값은 관측이 아니다.** 위험도 판정의 근거로 쓸 때 보간 비율을 함께 보고한다.
- 산·계곡 교량은 레이오버·그림자 영향을 받는다. 버스트별로 교량 입사 기하를 점검해야 한다(`bridge_conditions.py` G1·G2).
